Why this exists / 为什么我们做这个

Chrome print for labels is often blurry on thermal media. Default print settings in the browser are not tuned for Zebra label workflows.

Chrome 自带打印对热敏纸不友好，默认缩放/DPI 往往导致二维码和文字发虚。我们用本地打印桥接避免这一点。

How it works / 工作原理

  1. Chrome extension receives the PDF content and selected page size from the browser.
  2. Local helper converts and generates printer-ready label data.
  3. Data is sent to macOS CUPS queue for your configured Zebra printer.

3-step setup / 三步快速上手

  1. Step 1 安装扩展：安装 Chrome 扩展并固定到工具栏。
  2. Step 2 安装本地 App：下载并运行一次 App，完成 native host 注册。
  3. Step 3 打印标签：返回 Chrome，点击 Check Printer → Print Selected PDF。

Chrome extension entry / 扩展入口

Open Chrome Web Store Manage extension in Chrome
  1. 打开扩展弹窗后先点 Check Printer。
  2. 如果是本地 file:// PDF，请开启 extension 的“Allow access to file URLs”。
  3. 选择 “Print Selected PDF” 或 “Print Latest PDF”。

FAQ / 常见问题

  • Can it print labels from Chrome preview directly? Yes. Open the PDF in Chrome and trigger print in the extension.
  • 是否必须重装本地 App？ 不需要。第一次安装后打开一次即可，后续重启机器通常可直接使用。
  • 是否只支持 Zebra？ 当前优化重点在 Zebra 工作流与常见 macOS 打印队列。其他机型建议先小批量验证。
