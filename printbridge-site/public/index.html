Why this exists / 为什么我们做这个

Chrome print for labels is often blurry on thermal media. Browser defaults are built for ink/office pages and don’t match Zebra label DPI or page fitting behavior.

Chrome 自带打印对热敏纸不友好，默认缩放/DPI 往往导致二维码和文字发虚。我们改由本地助手处理输出，减少模糊。

How it works / 工作原理

  1. 1

    Browser capture / 浏览器读取

    Extension picks PDF, page boundaries, and requested label size from Chrome.

  2. 2

    Local conversion / 本地转换

    Native helper prepares printer-ready payload with optimized DPI for thermal output.

  3. 3

    Direct queue send / 直接落盘

    Converted label data is sent to your Zebra printer queue in CUPS.

3-step setup / 三步快速上手

  1. Step 1 安装扩展: 点击安装并固定到 Chrome 工具栏。
  2. Step 2 安装 App: 下载并运行一次本地 App，完成 native host 注册。
  3. Step 3 开始打印: 回到 Chrome，点击 Check Printer → Print Selected PDF。

FAQ / 常见问题

  • Can it print labels from Chrome preview directly? Yes. Open the PDF in Chrome and trigger print in the extension.
  • 是否必须重装本地 App？ 不需要。第一次安装后打开一次即可，后续重启机器通常可直接使用。
  • 是否只支持 Zebra？ 当前优化重点在 Zebra 工作流与常见 macOS 打印队列。其他机型建议先小批量验证。
